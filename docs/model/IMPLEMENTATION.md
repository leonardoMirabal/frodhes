# Frodhes: implementation plan (v2)

> **Superseded by [IMPLEMENTATION-v3.md](IMPLEMENTATION-v3.md)**, the self-contained plan written by the final review.

This is the working plan for building Frodhes, a physically modelled Rhodes for the M-VAVE FM-1. It merges
[PLAN.md](PLAN.md) (v1) with the four reviews in [`reviews/`](reviews/):

| Review | Lens |
|---|---|
| [01](reviews/01-dsp-realism.md) | DSP and physics realism |
| [02](reviews/02-embedded-perf.md) | embedded performance |
| [03](reviews/03-ui-product.md) | UI and product |
| [04](reviews/04-process-completeness.md) | process and completeness |

**Precedence:** this document wins over PLAN.md. Where it says "spec: Rxx §y", the detailed spec in that review
section applies as written, with the changes listed here. References like R01–R08 point to `research/0N-*.md`;
V01–V04 point to `reviews/0N-*.md`.

**Goal, in order of priority:**
1. a Rhodes that sounds real;
2. on the FM-1, within its hard limits;
3. a reface CP-style panel and effects;
4. tempo, scales, sustain and presets.

**Hard limits** (RULES.md):
- integers only: no float, no 64-bit `/` or `%`;
- 44.1 kHz audio in 256-frame ISR blocks, with < 2.9 ms per block for everything;
- about 96 KiB of RAM and about 336 KiB of pool;
- a 256 B settings sector;
- GPL-3.0-only.

## 1. Decisions (resolved)

### 1.1 Sound model

| # | Decision | From | Notes / conflicts resolved |
|---|---|---|---|
| S1 | **Modal tine** synthesis. No finite differences or port-Hamiltonian solver at run time. | PLAN D1, all research | — |
| S2 | **The physics lives in the host generator, not the ISR.** The generator runs: an FE tine plus tuning-spring model per key (73 service-manual lengths); a 2-DOF tine–tonebar solve; a coupled hammer–felt contact simulation; and a radial pickup field. The ISR runs only resonators, a pulse player and a pickup lookup. | V01 #4 #5 #6 | V04 lists "tine lengths as model input" for discard. **Rejected:** the FE model is what predicts the per-key ratios (7.1 at F1 down to about 6.4 at C7) and the strike weights. The lengths are published facts, not code. |
| S3 | **Normal modes per voice:** V1 = tine–bar sustain mode, tuned **exactly to f0**; V2 = the other tine–bar normal mode; O1/O2 = 2nd/3rd tine modes; H1 = horizontal polarisation (Phase 3). Weights come from the 2-DOF residues, not hand-set. | V01 #3 #4 | Replaces PLAN's symmetric `f0(1 ± δ)`, which made the pitch drift. |
| S4 | **Per-key partial ratios** come from the FE model, fitted to the F1 SLDV ratios (7.11/20.25) and to the jRhodes roots. | V01 #6 | Replaces the global 7.1/20. |
| S5 | **Pickup** = R03's flux family, used **radially**: the table is indexed by s = (x_v + off)² + x_h² in gap² units (one 1-D table per gap family, 2 families). TONE and voicing are an **offset** added to x_v, not a blend of tables. | V01 #3 #10 | V04 discards the "2-D field table". This is not a 2-D table: it is one 1-D table indexed by s, which adds H1 for 2 multiplies. V02 suggested pre-blending tables; that isn't needed once TONE is an offset. |
| S6 | **Pickup numerics:** the tip stays **int32 Q24 (gap units), never Q15**. The output is the exact box-averaged difference. Default: **cubic Hermite in s on an int32 Φ̃ table plus a Q15 slope table** (≥ 92 dB in every V01 case). The midpoint `D(s̄)·Δs` form (3 multiplies) is the fallback if Phase 0 shows the cost matters. | V01 #1, V02 C1 | V01 and V02 agree that Q15 is a blocker (4–17 dB SNR on soft E1). V02's int32 lerp gives 39 dB on soft E1 in V01's test, so Hermite is chosen. |
| S7 | **Resonator kernel: decided by a measured bake-off (task P2-2) between MC3 and DF2+EF1.** Both carry over: Q30 coefficients, int32 state, `mul` via the 64-bit product, mode-outer/sample-inner loops, and the damping coefficient rounded toward *more* damping. | V01 #2 vs V02 C2 | **Conflict.** V01 measured damped magic-circle MC3 at 110/55 dB (it also gives the quadrature that amplitude→pitch needs). V02 measured direct form with first-order error feedback at −135/−97 dB, with a clean voice end, and coupled-form floor leaving a 226 LSB residual. The bake-off uses each review's own test (`scratch-01/res.py`, `scratch-02/reson.c`) plus: decay to `alive = 0` within 2·T60 + 50 ms, C9 noise, cost on device. MC3 gets error feedback too if its residual blocks the voice end. |
| S8 | **Hammer:** a run-time pulse player, but the pulses are **generated by a coupled contact simulation on the host** (felt power law, the tine's first 6 FE modes plus the bar, 16× fs). Contact time **shrinks with velocity** (about 4× over 30 dB). MIDI velocity maps to hammer **speed** (dB-linear, R_dB = 30). | V01 #5 | The effective tine mass at the strike point is 21–43 g, so the interaction is not negligible. |
| S9 | **Same-note re-strike adds to the ringing tine** (superposition). Fade-and-clear applies only when stealing a voice for a *different* note. | V01 #7 | Replaces EP-MK1's retrigger clear. |
| S10 | **Damper:** per-mode release coefficients come from adding felt damping **on the tine coordinate** in the 2-DOF solve. Crossfade over about 5 ms (stable: convex combination of two stable pole pairs). The damper thump is injected on the tine coordinate. | V01 #4 #15, V02 C13 | Release targets are soft (±25–50 %): they are sfz settings, not measurements. |
| S11 | **One RLC load biquad on the mono mix** per TYPE, not per voice. Default 5 kHz, Q ≈ 1, set by ear. | V01 #11, V02 C10 | Excluded from automated spectral checks. |
| S12 | **Amplitude→pitch:** V1/V2's E depends on mode amplitude, updated per block and fitted from jRhodes loud vs soft layers. | V01 #14 | Replaces PLAN's separate decaying offset. |
| S13 | **Upper-mode attack residual** (modes ≥ 4, first 20–50 ms) is a precomputed tip-displacement table per band and layer, added to x_v (Phase 3). | V01 #13 | Replaces EP-MK1's "hammer into pickup" hack. |
| S14 | **Tone-bar-clip step** at key 54. Per-key log-T60 interpolation must allow it, not one smooth curve. | V01 #18 | — |
| S15 | **Seeded per-key jitter** (bar detune, level, T60, offset) within the fit residuals (Phase 3). | V01 #20 | — |
| S16 | **2× pickup oversampling is not planned.** It becomes automated check C8. Add it only if C8 fails (≤ −60 dB). | V01 #12 | Also "keep Φ smooth" is **rejected**. |
| S17 | **Run-time coefficient path** for TUNE, pitch bend, DECAY and RELEASE scale: the host tables give the base E and eps per key. Pitch scales E through a 2^(c/1200) mantissa LUT (exact via a sin table if the tests need it). DECAY scales eps through a reciprocal-scale table. All of this runs in the main loop (or ISR at event time), with no division. | V04 #3 | Unit test: ≤ 0.2 cent and ≤ 1 % T60 at every corner, keys 21–108. |
| S18 | **TYPE** = physically named deltas from the jRhodes-fitted '77 Stage: **STAGE '77**, **SUITCASE** (Peterson EQ, stereo vibrato is *offered*, not forced), **EARLY FELT**, **BELL/DYNO**. A TYPE change affects **new notes only**. | V01 #16, V03 #5 | Replaces MK I / MK II / BRIGHT, which rested on shaky history. |
| S19 | **Float golden model** (`tools/rhodes_model.py`) with exactly the C structure. **Gate A:** golden vs jRhodes. **Gate B:** C vs golden, residual ≤ −60 dB per case. | V01 #9 | — |
| S20 | **Fit by analysis-by-synthesis** on EQ-invariant measures: decay slopes from −5 to −35 dB above the noise floor, ripple rate and depth, frequency ratios, harmonic ratios *relative to the softest layer*. Only at root keys and at layers that exist. | V01 #8, V04 #4 | Sample lengths are **not** T60s. |

**Discarded (sound):**

| Item | Why |
|---|---|
| Uniform-beam ratios | The real tine has a tuning spring; S2/S4 replace them. |
| Symmetric tonebar detune | Pitch drift; S3 replaces it. |
| H1 summed into x | Wrong physics; S5 routes it radially. |
| TONE as a table blend | The offset is the physical control (S5). |
| Q15 tip/Φ | Blocker-level SNR (S6). |
| "Round toward zero" | Shortens soft-bass T60 by 28 % (S7). |
| EP-MK1's 1/f0 hammer, 2 kHz HPF, hammer-into-pickup, waveshaper chain, constant Q | All non-physical; replaced by S2–S13. |
| STK Rhodey voice or FM bark layer | Not physical and aliases. Kept **only** as the low anchor in blind listening tests. |
| rdpiano log-domain envelopes | Our decays come from the resonator poles. |
| Felucca's SVF modal bank | Uses 64-bit divisions and costs about 13 % per voice. |
| Pfeifle pole profile, arc trajectory, pickup back-force, K1/K3 damper spring | V01 ledger. |

### 1.2 Platform and real time

| # | Decision | From |
|---|---|---|
| P1 | **The ISR owns all voice state.** The main loop posts 32-bit events (`NOTE_ON key vel`, `NOTE_OFF`, `PEDAL`, `ALL_OFF`, `PARAM id val`) into an SPSC ring of 32 entries. The ISR drains it at the start of each block. `rh_lit` and `rh_quiet` read ISR-written summary words. | V02 C3 (replaces the `strike` handshake in V01 S2/S3) |
| P2 | **ISR budget split:** voices ≤ 1.9 ms, effects ≤ 0.5 ms, margin ≥ 0.5 ms (includes TIMER5/USB nesting). Worst case = 8 voices struck in one block, bass, v = 127, pedal, all effects, A.DLY at maximum, USB audio streaming. | V04 #5 #9, V01 #19 |
| P3 | **Hot tables in the pool:** the 2 pickup families are copied from flash at boot. Per-key coefficient rows stay in flash (read only at note-on). | V02 C6 |
| P4 | **`fxp.h`**: the only place for Q helpers (`mul30`, `mul24`, saturating adds, lerp, Hermite, round-up), with host tests proving no libcalls (`scratch-02/mul64.c`). | V02 §B |
| P5 | **ROM-window safety:** never mask table bases (`x >> k` for the index, `x & mask` for the fraction); no hard-coded Q30 literals (they belong in generated tables); the generator nudges any table word that falls in 0xFFC00000–0xFFCFFFFF. | V02 C7 |
| P6 | **Time base** is `fm1_ticks()` (24 MHz, wraps at 2³²). Ticks → samples = `((uint64_t)t * 7892002u) >> 32`. **Never use `fm1_micros()`**, which wraps at 178.9 s. | V02 C5 |
| P7 | **Flash writes** go through `app_flash_begin/end()`: they need `rh_quiet() && fx_quiet()` (effect output below −80 dBFS for 500 ms), zero the audio buffer before the erase, and flush the delay and reverb lines afterwards. | V02 C4, V03 #9 |
| P8 | **Profiler stays in the firmware:** per-stage µs, max and mean per second, a "late" counter, and an overload shedder that fades out the oldest voice after 2 blocks above 85 %. Shown on a CPU page and sent as a SysEx dump. | V02 C8 §E, V04 #9 |
| P9 | **Block buffers are static**, off the 7.9 KiB ISR stack. Never call `irq_save/irq_restore` from ISR code. | V02 C11 |
| P10 | **Draw scheduler:** at most one screen element per main-loop pass, priority hot cell → header → footer → columns. Try `LCD_BAUD=2` in Phase 0. | V03 #7 |
| P11 | The "no 64-bit division" rule stays. Phase 0 probes once whether the toolchain inlines it (Felucca does), so RULES.md can state the facts. | V02 C18 |

| # | Decision | From |
|---|---|---|
| U1 | **The PANEL has 7 reface columns:** TYPE, DRIVE, TREM/WAH, CHO/PHA, DELAY, REVERB, VOLUME (read-only MASTER). Each is 34 px wide. | V03 #1 |

## 2. Architecture

### 2.1 Audio path (ISR, every 256 frames)

```
app_audio(out, 256):
  prof_begin()
  rh_render(rh_mono, 256)          drain event ring → voices: 16-frame blocks; mode-outer loops;
                                   pickup per voice; Σ per-key gain into rh_mono (int32)
  rh_post(rh_mono)                 RLC load biquad (per TYPE), master voice gain
  fx_render(rh_mono, out, 256)     DRIVE → TREM/WAH (stereo from here) → CHO/PHA → DELAY → REVERB → master
  prof_end(); shed_if_overloaded()
```

Spec: V02 §D gives the stage budgets and V01 S3–S5 the voice loops, with these changes:
- the event ring (P1) replaces the `strike` handshake;
- the pickup is the Hermite form (S6);
- the resonator kernel comes from the P2-2 bake-off.

### 2.2 Memory (spec: V02 §C, revised)

| Region | Contents | Est. |
|---|---|---|
| Flash | per-key rows (88 × ~96 B), pulses, velocity tables, Φ̃ + slope source tables, residuals (Phase 3), fonts, UI | ~45 KiB of tables |
| Pool | pickup tables (2 families × (int32 Φ̃ + Q15 G)) ≈ 24 KiB, delay 94–128 KiB, HALL 12.5 KiB, chorus 2 KiB, canvas (decided in P0-4) | ≤ 62 % used, ≥ 8 KiB spare enforced |
| RAM | 8 voices × ~200 B, static block buffers (`rh_mono`, fx scratch), event ring, profiler, settings mirror | < 8 KiB new |

### 2.3 Main loop

```
poll → keys (KEY VEL, scale map, per-key refcount, LED state) → buttons (state machine V03 §4.3)
     → encoders → MIDI in (notes, CC map, PC, clock stamps with fm1_ticks) → tempo_poll
     → post events / params → draw scheduler (one element) → deferred flash write (P7)
```

## 3. The voice (spec: V01 S0–S7, with S6, S7 and P1 applied)

1. **Generated tables** (`firmware/gen/rhodes_tables.h`, V01 S1): `rh_key_t` per key 21–108 (E, eps, eps_rel and
   b per mode; off, gain, kill, hc, kappa, prate, band, fam, res); `RH_PULSE[5][4][66]`; `RH_VAMP` and
   `RH_VRATE[5][128]`; `RH_VLAYER[128]`; Φ̃ and G for 2 families; `RH_RLC[4]`; `RH_RES` (Phase 3). The header
   carries the generator version and sha256 values. The output must be byte-identical across runs and OSes.
2. **Voice state:** V01 S2 minus the `strike/seen` fields (P1), plus the event-time fields. About 200 B per voice.
3. **Per block** (V01 S3): drain events (allocate: same note → re-strike superposition; else silent; else
   oldest damped; else oldest, with a 48-frame steal fade); damper ramp; amplitude→pitch; kill test.
4. **Per sample** (V01 S4): pulse lerp → modes (kernel from P2-2) → x_v, x_h → radial s → Hermite Φ̃ difference
   → `× gain` into `rh_mono`.
5. **Host generator steps:** V01 S7, steps 1–12 (FE tine, 2-DOF, overtones, coefficients rounded toward more
   damping, coupled hammer sim, b calibrated on the quantised recursion, pickup tables with asserts, off/gain/kill,
   RLC, jitter, emit). Add: the ROM-window nudge (P5).

## 4. Verification of realism

Checks C1–C11 in V01 S8, **with V04 #4's corrections**:

| Check | Rule |
|---|---|
| C1 tuning | ±2 c, plus first-half/second-half drift ≤ 2 c |
| C2 decay | per partial, two slopes (EDT 0 → −10 dB, late −10 → −35 dB above the measured noise floor), per root and matched layer. Late ±20 %, early ±30 %, breakpoint ±4 dB |
| C3 overtones | O1 T60 ≤ 0.25 × V1, O2 ≤ 0.1 × V1; frequency within ±1 % of the reference ratio |
| C4 release | soft target ±25 % (user RELEASE scale), no click (post-note-off HP residual < −50 dBFS), voice ends in time |
| C5 pickup unit test | as V01 S8 (2 unequal positive peaks, antisymmetry, pure overtone at off = 0, C vs float ≤ −70 dB) |
| C6 velocity and bark | monotonic RMS; output range v1 → v127 within 20–40 dB; bass layer spacing 2–5 dB; ΔB within ±3 dB of the reference at layer centres (24/60/84/104/120), with ≥ 50 % of the rise above v = 84 |
| C7 golden | C vs float ≤ −60 dB per case |
| C8 alias | ≤ −60 dB at keys ≥ C5, v = 127 |
| C9 noise | soft E1 C vs golden ≤ −60 dB; exact digital silence after every voice ends |
| C10 re-strike | superposition equals golden; no output gap |
| C11 device timing | the P2 worst case within the voices' 1.9 ms |
| Attack pitch (Phase 3) | within ±1.5 c of the reference |
| **T-LISTEN** | blind, randomised, RMS-matched within ±0.5 dB, STK Rhodey low anchor, written pass rule, report committed (V04 §5.1) |

Second, analysis-only reference: the UVI A4 8-force set (R03) for velocity→timbre, if available locally.

## 5. Effects (spec: R06 recommendations plus V03 fixes)

| Column | Switch (A / B) | K1 | K2 | Hold layer | Implementation |
|---|---|---|---|---|---|
| DRIVE | none | AMOUNT | none | none | port `track_dist`; per-TYPE bias/tone/make-up (level-matched) |

- **Delay knobs:** whether DEPTH is feedback plus level is an open question (Q6).

## 6. UI, tempo, scales, presets (spec: V03 §4 with U1–U12; R08 with P6)

**V03 §4 holds the detailed specs:**
- the PARAMS table (§4.1);
- pixel layouts with the real 8×16 and 16×32 fonts (§4.2);
- the button state machine (§4.3);
- the LED rules (§4.4);
- the 256 B settings record (§4.5);
- the 48 B preset record (§4.6);
- the 12 factory presets (§4.7);
- the tempo, sync and scale flows (§4.8);
- the host UI tests (§4.10).

**Changes to apply on top of V03:**
- SELECT defaults to DYN (U2), and BPM moves to GLO.
- Tempo maths uses `fm1_ticks()` (P6).
- Flash writes go through P7.

**Tempo:** `bpm10` 40.0–240.0; tap on PLAY (last 4 taps, set from the 3rd, reset after 2 s); MIDI clock follow
with stamps, a one-beat average, rejection and a 500 ms fallback; transport FA/FB/FC. The sync table is in
1/96-quarter units, FREE … 2BAR (+4BAR for chorus). The delay glides on changes.

**Scales:**
- **Modes:** OFF · SNAP · DEGREES.
- **Scales:** MAJ, MIN, DOR, MIX, LYD, PHRY, HARM, MEL, PEN, MPEN and BLUES, using Felucca's masks.
- **Note handling:** per-note reference counts; MIDI IN is not quantised.
- **DEGREES root:** whether it stays C4 or moves to F3 is open question Q7.

**Presets:**
- The panel is the sound, stored in the settings record.
- Factory presets are const tables.
- 16 user presets live in A/B torn-write-safe sectors. The location is decided in P0-4: not in 0xE0000– and not in
  0xFC000; this needs the `FL_RANGE_OK` hook.
- Program Change selects presets.
