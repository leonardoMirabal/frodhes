# scratch-05: experiments behind IMPLEMENTATION-v3.md

Run from this directory. Pure Python 3 + numpy, or `cc`. All physical inputs are ESTIMATES (the fit sets them);
the arithmetic is the firmware's (int32 state, Q30 coefficients, int64 products, floor shifts).

| Script | Settles | Result (2026-10-15) |
|---|---|---|
| `reson_bakeoff.c` | S7: MC3 vs DF2, each with/without first-order error feedback, same quantised coefficients, SNR re the *signal* (not re full scale), T60, residue after 2.5×T60, amplitude estimate | At a −60 dB E1 (peak 2^18): DF2-floor 19 dB, DF2-EF1 63 dB, MC3-floor 63 dB, **MC3-EF1 108 dB**. E2 soft 70 vs 103; A4 soft 76 vs 91; C7 soft 69 vs 79. Residue after 2.5×T60: DF2-EF1 up to 109 LSB, MC3-EF1 ≤ 22 LSB. Amplitude estimate (bass): MC3 x²+y² 0.15–0.35 %, DF2 energy form 4–51 %. Coefficient quantisation: both < 0.02 c, < 0.003 % T60. **Decision: MC3 + EF1 on both states.** (V02's "−97 dB" for DF2+EF1 was re full scale during a loud segment; this test measures what matters, the quiet tail.) |
| `pickup_hermite_s.py` | S6: cubic Hermite in s vs midpoint D(s̄)·Δs vs lerp, 2048 cells over 32 gap², integer Horner | With the cell fraction taken as 22 bits straight from the Q48/Q50 product (HERM22): E1 soft 74 dB (tip Q24) / **80 dB (tip Q25)**, every other case ≥ 93 dB, alias ratio identical to exact ADAA (C7 1.5 gap −54 dB, E7 1.5 gap −39 dB, C8 1.0 gap −35 dB). A 16-bit fraction loses 20 dB (54 dB). The soft-bass floor is the tip quantisation, not the table. C5 pattern: 2.0 positive peaks/period, ratio 0.78, antisymmetry 1.0000. 19 slope-table words fell in the ROM window: the generator nudge (P5) is needed. The Q25 run was the same script with `Q24 = 1<<25`, `SH = 19`, shifts +2 (only the HERM22 column is meaningful in that copy). |
| `coefpath.py` | S17 for a DF2 kernel (kept as evidence; DF2 was not chosen) | ≤ 0.17 c, ≤ 0.012 % T60 over keys 21–108, 3 modes, S 0.25–4, c ±250. |
| `coefpath_mc3.py` | S17 for the chosen MC3 kernel: E and eps from sin(θ/2), cos(θ/2), θ, d, cr with no division | TUNE ±50 c: held **0.14 c**, T60 0.012 %; release (T60 0.125–0.5 s, S 0.25) 2.3 c. Bend ±250 c: held 0.38 c, release 2.8 c. The (1−r)² correction must be rescaled to the shifted angle (cr' = cr(1−2t+3t²)); without it: 7–28 c. |
| `tinebar_residue.py` | S3: 2-DOF residues; is a pure 2-pole per normal mode (force into the velocity state) adequate? | Residue phase error of the dominant tine mode −0.6..−11°; the weak bar mode +18..+52° but with weight 1–9 %. ESTIMATE parameters. |
