## New

- Akai MPC: `frodhes-mpc.zip`, an instrument plugin for MPC standalone hardware (MPC OS 3.10.1 or later, External
  Plugin Support on). The desktop plugin's engine: electric piano, vibraphone and marimba, the same effects, 16 voices
  on every instrument, the factory presets F01-F57 as programs, its pages on the MPC's screen and Q-Links. Not yet run
  on an MPC: install, what to report and how to build it in
  [docs/MPC.md](https://github.com/leonardoMirabal/frodhes/blob/main/docs/MPC.md).
