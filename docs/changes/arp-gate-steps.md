## Fixed

- ARPEGGIO page: after ARP GATE was set over MIDI to a value between the 5 % steps (such as 73 %), turning **GATE**
  kept the odd value (78 %, 83 % ...), so the round steps could not be reached. Now the first step of the knob lands
  on the 5 % step in the direction you turn, then it steps 5 %.
