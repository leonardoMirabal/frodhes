## Changes

- Desktop plugin: the drive's first type is now **WARM**, a warm, smooth overdrive of the plugin's own, in place of
  FDRV. It has the same knobs, the same CC 84 values and the same place in the presets (a preset with FDRV plays WARM).
  The other four drive types are unchanged. The FM-1, the Move and the MPC keep FDRV.
- Desktop plugin: the delay's code was rewritten. It sounds and responds exactly as before.
