## New
- Install from the browser: the emulator page installs Frodhes on the FM-1 (Chrome or Edge, MIDI with SysEx): **Install on your FM-1**,
  **Find my FM-1**, then **Install**. It runs the same update as `tools/fm1_install.py`, checks the package and its
  sha256 first, and checks the FM-1's identity after the restart. An install that was cut off gets **Resume the
  install**. Safari and Firefox get the terminal installer's command instead.
