**Frodhes 0.9.15** brings 14 voices to the SMK-37 keyboards, lets a re-struck note pick up the voice settings you just changed, puts WHURLI on an SMK-37 pad in the menu's order, and keeps the sequencer's playhead moving while you move a fader.

**Download:** `frodhes.fwsc` below (the same file as `frodhes-0.9.15.fwsc`; the newest is always at https://github.com/leonardoMirabal/frodhes/releases/latest/download/frodhes.fwsc). **Try it first in your browser:** https://leonardomirabal.github.io/frodhes/

### Install

**FM-1**: download `frodhes.fwsc` below. Install it from the [emulator page](https://leonardomirabal.github.io/frodhes/#install) (Chrome or Edge, **Install on your FM-1 or SMK-37**), or from a terminal:

```sh
pip install mido python-rtmidi
python3 tools/fm1_install.py frodhes.fwsc
```

Your settings, presets and pattern are kept. If anything goes wrong, switch the FM-1 off, hold **OCT−** and switch it on: that is the USB rescue, and you can install again from there.

**Computer (plugin)**: `frodhes-plugin-macos.pkg` (or `frodhes-plugin-macos.zip`), `frodhes-plugin-windows.zip`, `frodhes-plugin-linux-x86_64.zip` or `frodhes-plugin-linux-aarch64.zip` below. How to install each: [PLUGIN.md](https://github.com/leonardoMirabal/frodhes/blob/main/docs/PLUGIN.md#packages).

**Move**: you need Schwung on the Move. Install Frodhes with Schwung Manager in a web browser: **Install Custom Module > From GitHub URL**, `leonardoMirabal/frodhes`. Or download `frodhes-module.tar.gz` below and use **From Tarball**. Details: [the Move manual](https://github.com/leonardoMirabal/frodhes/blob/main/docs/MOVE.md#install).

**Akai MPC**: `frodhes-mpc.zip` below (MPC OS 3.10.1 or later, External Plugin Support on). Copy its folder `Frodhes - VST - Frodhes` into `VST2 Plugins` at the top of the MPC's drive. Details: [MPC.md](https://github.com/leonardoMirabal/frodhes/blob/main/docs/MPC.md#install-and-remove).

**SMK-37 Pro, SMK-37 Elite, MKE-P37**: `frodhes-smk37-pro.fwsc`, `frodhes-smk37-elite.fwsc` and `frodhes-mke-p37.fwsc` below. Read [SMK37.md](https://github.com/leonardoMirabal/frodhes/blob/main/docs/SMK37.md) first.

### New in 0.9.15
- **SMK-37 Pro, SMK-37 Elite and MKE-P37: 14 voices**, as on the FM-1. The voices run on one processor core and the
  effects on the other, so the keyboards play as many notes at once as the FM-1.

### Changes
- **A re-struck note takes the settings you just changed.** Each note keeps the voice settings it was struck with. Until
  now a note struck again while it still rang kept its first settings too. Now, when you changed TONE, BARK, BELL,
  HAMMER, DECAY, RELEASE, SPREAD, TUNE or the TYPE since the note was struck, the new strike starts with the new
  settings and the old sound fades out within a couple of milliseconds. With nothing changed, a re-strike sounds
  exactly as before. On every instrument type, on the FM-1, the SMK-37, the Move and the plugin.
- **SMK-37 pads 1 to 7 follow the TYPE menu's order**: the four tine pianos, then WHURLI (pad 5), VIBES (pad 6) and
  MARIMBA (pad 7). Pad 8 is the next preset; turn the PRESETS knob back for the previous one.

### Fixed
- The sequencer's playhead and its NOW / NEXT notes stood still on the screen while a fader (SMK-37) or a knob kept
  moving. They keep running now.
- The Firmware Hub offers each new release again: 0.9.12 to 0.9.14 shipped without the file name the hub follows, so
  it kept offering 0.9.11. The hub's card now shows the current description and picture.
