**Frodhes 0.8.1**: a physically modelled Fender Rhodes electric piano for the M-VAVE FM-1. Every note is computed live from the mechanics of a Rhodes (hammer, tine, tonebar, pickup); there are no samples.

**Download:** `frodhes-0.8.1.fwsc` below (package identity `FM-1_958`).

**Try it first in your browser:** https://leonardomirabal.github.io/frodhes/

### Install
```sh
pip install mido python-rtmidi
python3 tools/fm1_install.py frodhes-0.8.1.fwsc
```
If anything goes wrong, switch the FM-1 off, hold **OCT−** and switch it on to get the USB rescue, then install again.

### What's in it
- Four instrument types: Stage 77, Suitcase, Early Felt, Bell Dyno. The tone, bark, bell, hammer, decay, release and noise are all adjustable.
- Effects: compressor, drive, tremolo / auto-pan / wah, phaser, chorus, delay (digital / analog) and reverb. Each effect keeps about the same volume when you switch it on, and **FX** switches all of them off and on at once.
- The compressor has 4 knobs (threshold, ratio, attack, makeup) and **new in 0.8.1:** a gain-reduction meter on its page, like a hardware compressor.
- A look-ahead limiter, so big chords stay clean on the USB audio and the headphone jack alike.
- Tap tempo with MIDI clock sync, scales (snap / degree), a sustain pedal on REC, and 12 factory plus 16 user presets.
- One page per section, with four cards for the four knobs. See the [manual](https://github.com/leonardoMirabal/frodhes/blob/main/docs/MANUAL.md).

Built on [Dinghy](https://github.com/zvenson/dinghy). GPL-3.0.
