**Frodhes 0.9.0**: a physically modelled Fender Rhodes electric piano for the M-VAVE FM-1. Every note is computed live from the mechanics of a Rhodes (hammer, tine, tonebar, pickup); there are no samples.

**Download:** `frodhes-0.9.0.fwsc` below. **Try it first in your browser:** https://leonardomirabal.github.io/frodhes/

### Install
```sh
pip install mido python-rtmidi
python3 tools/fm1_install.py frodhes-0.9.0.fwsc
```
If anything goes wrong, switch the FM-1 off, hold **OCT−** and switch it on to get the USB rescue, then install again.

### New in 0.9
- **PERFORM**, the new first page: four knobs for playing. By default they are the dry / wet of trem/wah, phaser, chorus and delay, and turning one up switches that effect on. On the **ASSIGN** page you choose what each knob plays (27 choices). **HOME** switches between PERFORM and the main page.
- **Arpeggiator** on the **ARP** button: up, down, up-down, as played or random; 1/4 to 1/32 locked to the tempo (tap tempo and MIDI clock too); 1 to 4 octaves; gate. **PLAY** on its page switches **HOLD**, which keeps the arpeggio going after you let go of the keys.
- **Compressor gain-reduction meter**, like a hardware compressor's.
- **Scales:** SNAP now moves a note to the *nearest* scale note, and the root's keys glow dimly so you can find the keynote.
- **Big chords keep every note:** 8-note chords no longer lose notes.
- **Headphones:** the volume no longer flutters when headphones are plugged in. A new **USB VOL** setting on SETUP keeps the USB audio at full level whatever the MASTER knob does.
- A start screen, and the main page is titled FRODHES.

The DELAY page is now reached with SELECT (or from its PERFORM knob), since ARP opens the arpeggiator.
