How to play

Computer keys play the keyboard: A is F3, W S E D R F G Y H U J K O L P ; go up chromatically. Z / X = OCT− / OCT+, Space = REC (sustain), ← → = SELECT (pages), ↑ ↓ = PRESETS.

Knobs: turn with the mouse wheel or drag up / down. Buttons can be held (REC, SAVE). A MIDI keyboard works through Web MIDI (Chrome, Edge). Settings are kept in this browser; user presets last until you reload.
